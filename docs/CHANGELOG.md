# Історія змін — Whisper Fast GUI

Цей файл винесено з `README.md`, щоб README міг залишатися коротким індексом (див. [README.md](../README.md)). Поточна версія та дата публікації як і раніше зберігаються тільки в `README.md` — саме звідти їх читає `whisperfast/config.py` (`parse_app_metadata`) і механізм перевірки оновлень (`whisperfast/updates/app_updates.py`). Якщо потрібно розібратися, як саме це працює — [UPDATES.uk.md](UPDATES.uk.md).

## Що нового в 1.2.15

- **install.bat:** `pip` через `python.exe` (не `pythonw`); після установки запуск лише через `run_whisper.vbs`.
- **CUDA:** батник завжди питає «У вас відеокарта NVIDIA?» — так ставить CUDA, ні пропускає й продовжує CPU, навіть якщо автоперевірка GPU нічого не знайшла.
- **Залежності:** якщо один пакет у групі падає, решта ставиться окремо; якщо CUDA-колесо PyTorch недоступне (часто Python 3.13) — CPU-збірка з PyPI.

## Що нового в 1.2.14

- **Залежності:** діалог «Force reinstall?» показується мовою інтерфейсу (для RU раніше лишався англійський текст).
- **Іменована папка виходу:** повторна обробка файлу, який уже лежить у такій папці, більше не створює вкладення `talk/talk/talk.mp4`.
- **Скрипт:** `scripts/download_facebook_videos.py` — завантаження Facebook-відео через yt-dlp.

## Що нового в 1.2.13

- **Оновлення програми:** достатньо GitHub Release і обов’язкового SHA-256 (`SHA256SUMS`). GPG-підпис не потрібен і не вмикається (немає ключа в `resources/`).

## Що нового в 1.2.12

- **Оновлення програми:** ZIP більше не береться з гілки `main`. Ставиться асет з GitHub Release після обов’язкової перевірки SHA-256 (`SHA256SUMS`); без контрольної суми оновлення не пропонується. Опційно — GPG-підпис, якщо в `resources/` є публічний ключ.
- **Надійність:** захист від zip-slip при розпакуванні, безпечніше застосування оновлення на Windows (`_apply_update.py`), перевірка типів у `settings.json`.
- **Черга:** контракт `TranscriptionHost` і тести `QueueController` / `run_queue` без запущеного GUI.

## Що нового в 1.2.11

- **Залежності / Оновлення:** pip-команди видно в логу; FFmpeg і Pandoc ставляться автоматично (winget / Chocolatey / Homebrew або завантаження в `tools/`), без ручного копіювання інструкцій.
- **MD → Word:** якщо Pandoc немає, програма пропонує встановити його одразу.
- **Claude:** провайдер Anthropic у вікні промптів і в **API keys** (ключ + модель; без ключа — браузер claude.ai).

## Що нового в 1.2.10

- **Відео:** підтримка `.webm`.

## Що нового в 1.2.9

- **`redactor1.md`:** промпти №1–№4 стиснуті в структуровані `<system>` / input-блоки з плейсхолдерами (`{{TRANSCRIPT_TEXT}}`, `{{INPUT_DATA}}` тощо).
- **Промпт №1 «redactor»:** замість трифазного RU/UK/EN пайплайна — один компактний system-промпт (мова джерела, UK 2019, збереження термінів і повного змісту).
- **TW_core / brutally honest / Post_mortem:** короткі фреймворки з self-correction директивами замість довгих інструкцій.
- **PMO1:** очищена Markdown-розмітка секцій (`###` замість `===`); PMO2 без змін логіки.

## Що нового в 1.2.8

- **Лог — 3 рівні згортання:** день → файл → транскрипція / створені файли (`▼`/`▶`); сьогодні розгорнуто, минулі дні згорнуті.
- **Заголовок дня:** після дати кількість оброблених файлів `(N)`; порожні дні (без file-сесій) прибираються з `app_log.json` при старті.
- **Створені файли:** окрема кнопка «Обрати промти» в секції (не змішаний action-рядок).
- **Стабільніше згортання днів:** тіло дня вивантажується при згортанні (без зламаного вкладеного elide).

## Що нового в 1.2.7

- **Оновлення при старті:** перевірка версії на GitHub; діалог **Оновити / Пізніше / Пропустити цю версію**.
- **Реліз-ноти:** `resources/release_notes.json` (EN/UK/RU); кнопка версії `vX.Y.Z (дата)` відкриває «Що нового».
- **Мова в відкритих вікнах:** зміна мови оновлює Help, реліз-ноти, вікна промптів та інші зареєстровані діалоги.

## Що нового в 1.2.6

- **Лог:** згортання/розгортання блоків файлів кліком по заголовку (`▼`/`▶`).
- **Відео:** підтримка `.wmv`.
- **Исходник поруч із результатами:** після успішної обробки джерело переноситься в каталог вихідних файлів (черга і лог оновлюють шлях).
- **Конфлікт імен:** діалог **Так / Ні / Пропустити** — перезапис, суфікс `_HHMM` або пропуск запису.
- **Whisper і «Промты»:** черга Whisper не стоїть на виборі промптів; можна кілька вікон промптів одночасно.

## Що нового в 1.2.5

- **Один екземпляр:** при повторному запуску — діалог «ПЗ вже запущено» з вибором: вбити попередній, нічого не робити або запустити ще один.

## Що нового в 1.2.4

- **Лог file-сесії:** усе по одному вхідному файлу (сегменти, TXT/SRT/MP3/MD, AI-результати, події) — один JSON-об’єкт і один блок у вікні логу.
- **Швидший `app_log.json`:** batch flush на диск; сегменти зберігаються зведеними (лічильник + останні прев’ю), без окремого рядка на кожен сегмент.
- **Lazy UI:** минулі дні — лише заголовки; тіло підвантажується при розгортанні.
- **Провідник (Windows):** Shift+клік по шляху надійніше відкриває Explorer через `ShellExecuteW` `/select,"…"`.

## Що нового в 1.2.3

- **В AI:** чекбокс і кнопка замість «В Cursor»; вибір інтеграції у вікні промптів — **Cursor**, **Gemini**, **Claude**, **Copilot** (Azure OpenAI).
- **Вікно промптів:** галочки, **Виконати** / **Пробіл**, **Всі**, перший промпт відмічений за замовчуванням; закриття = пропуск AI з можливістю відкрити знову з логу.
- **API + fallback:** Cursor SDK / Chat; Gemini API / браузер; Claude (Anthropic) API / браузер; Azure OpenAI / браузер Copilot. Ключі в одному діалозі **API keys**.
- **Лог:** збереження в `app_log.json`, секції по днях зі згортанням; сьогодні завжди розгорнуте.
- **i18n:** повідомлення про помилки винесені в `lang.json` (EN/UK/RU).
- **Провідник:** Shift+клік по шляху в логу знову відкриває видиме вікно Explorer (без прихованого запуску).

## Що нового в 1.2.2

- **Без вікна консолі при Cursor:** на Windows Chat і cursor-sdk bridge запускаються без `.cmd`-обгорток (`Cursor.exe`/`node.exe` + `CREATE_NO_WINDOW`), консоль більше не лишається відкритою.
- **Стійкіший Cursor SDK:** окремий bridge на кожен промпт, drain stderr і повтор при `WinError 10061` (відмова з’єднання до «мертвого» bridge).
- **Конфлікт імен вихідних файлів:** якщо цільовий файл уже є — діалог перезапису або збереження з суфіксом `_HHMM`.
- **FFmpeg / Pandoc:** окремий модуль підказок і перевірки оновлень зовнішніх утиліт; інструкції встановлення в README та в логу [Система] / [Залежності].
- **Відкриття шляхів:** спільний helper для відкриття файлу / показу в провіднику з логу.

## Що нового в 1.2.1

- **Документи в черзі:** `.md`, `.txt` та інші текстові формати; `.pdf`, `.doc`, `.docx` конвертуються в Markdown (`markitdown`), без виклику Whisper.
- **Cursor для документів:** у промпти передається Markdown; у логу фіксується, що вихідний PDF/DOC/DOCX у Cursor не передавався; кроки й результати обробки видно в логу.
- **MD → Word:** опція експорту Markdown у `.docx` через Pandoc (після MD або після кожного результату Cursor).
- **Залежності «по максимуму»:** [Залежності] / [Оновлення] ставлять повний набір pip-пакетів, зокрема `markitdown[pdf,docx,pptx,xlsx,xls]`, `cursor-sdk`, `packaging`.
- **FFmpeg і Pandoc:** після установки та в [Система] — перевірка; якщо відсутні — покрокові команди (winget / Chocolatey / Homebrew / apt) і нагадування перезапустити програму після оновлення PATH.
- **Оновлення:** перевірка версії програми на GitHub виконується першою в списку [Оновлення].

## Що нового в 1.2.0

- **Пакет `whisperfast/`:** код розкладено за шарами (`core`, `ui`, `i18n`, `setup`, `updates`, `postprocess`); `main.py` лишається точкою входу в корені.
- **Ресурси:** іконка, звук і довідка перенесені в `resources/`; `lang.json` — у `whisperfast/i18n/`.
- **Рефакторинг:** транскрибація, діалоги, трей і налаштування винесені з `gui.py`; DRY для subprocess/Windows і парсингу версії з README.

## Що нового в 1.1.6

- **Збереження:** кнопка «Сохранение» замість поля шляху; режими — поруч із відео, вибраний каталог або підкаталог із шаблоном `{basename}`.
- **MP3:** чекбокс + кнопка «mp3»; місце збереження — як у «Сохранение», поруч із відео або окремий каталог.
- **Компактний UI:** «Слежение» відкриває список каталогів (без окремої «Каталог»); «В Cursor» відкриває `redactor1.md` (без окремої «Изменить промт»).

## Що нового в 1.1.5

- **Слідкування за кількома каталогами:** прапорець «Слідкування» + кнопка «Каталог»; шляхи зберігаються в `settings.json` через кому.
- **Надійне підхоплення завантажень:** новий файл спочатку в pending (вік ≥ 10 с, розмір стабільний ~15 с, файл відкривається); опитування кожні 10 с; при помилці декодування — до 2 retry.
- **Черга винесена в `queue_manager.py`:** persist `request_queue.json`, додавання/видалення та логіка слідкування в одному модулі.
- **Імена файлів Cursor:** замість `*_edited.md` використовується назва промпта з лапок (`## Промпт №2 "TW_core"` → `*_TW_core.md`).

## Що нового в 1.1.4

- **Вибір Python при першому запуску:** програма знаходить установлені інтерпретатори, пропонує вибір, якщо їх кілька, та зберігає `python_path` і `python_version` у `settings.json`.
- **Єдина версія Python для запуску й залежностей:** `run_whisper.vbs`, `start_delayed.vbs` та `install.bat` використовують збережений інтерпретатор.
- **Cursor SDK на Windows / Python 3.10–3.11:** додано сумісність для запуску локального bridge та послідовної обробки всіх промптів.
- **Компактний UI:** елементи MP3, каталогів і Cursor згруповано в один рядок; поле каталогу збереження скорочено до третини початкової ширини.
- **API-ключ:** кнопка `api_key` відкриває окреме вікно; ключ змінюється лише після натискання «Зберегти», закриття через X скасовує зміни.
- **Залежності:** `cursor-sdk` перевіряється та встановлюється через [Оновлення] / [Залежності].
- **Черга:** у запиті про обробку тільки нових файлів показується їх кількість.
- **Сигнал завершення:** при ввімкненому «У Cursor» звук відтворюється лише після завершення транскрибації та всієї Cursor-постобробки.

## Що нового в 1.1.3

- **Видалення з черги:** виділені файли можна прибрати клавішею Delete або через контекстне меню (ПКМ → «Видалити»); підтримується групове виділення (Ctrl/Shift).
- **Довідка мовою інтерфейсу:** кнопка [Довідка] відкриває `Help_EN.md` / `Help_UK.md` / `Help_RU.md` залежно від обраної мови (EN / UK / RU).
- **Постпроцесинг TXT у Cursor:** прапорець «У Cursor», промпти в `redactor1.md`, API-ключ у `settings.json` / `CURSOR_API_KEY`; без ключа — відкриття Chat.

## Що нового в 1.1.0

- **Оновлення самої програми** з GitHub ([magnusua/WhisperFastGUI](https://github.com/magnusua/WhisperFastGUI)) через кнопку [Оновлення].
- **Оновлення ваг Whisper** (Hugging Face Hub) — у загальному процесі оновлень і окремою кнопкою «Оновити модель» у діалозі вибору моделі.
