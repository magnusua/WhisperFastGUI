# Історія змін — FTW (раніше Whisper Fast GUI)

Цей файл винесено з `README.md`, щоб README міг залишатися коротким індексом (див. [README.md](../README.md)). Поточна версія та дата публікації як і раніше зберігаються тільки в `README.md` — саме звідти їх читає `whisperfast/config.py` (`parse_app_metadata`) і механізм перевірки оновлень (`whisperfast/updates/app_updates.py`). Якщо потрібно розібратися, як саме це працює — [UPDATES.uk.md](UPDATES.uk.md).

## Що нового в 2.0.8

- **Telegram у шапці:** галочка ліворуч від іконки запускає або зупиняє слухача. Якщо акаунт або бот ще не заповнені, FTW просить спочатку відкрити налаштування Telegram.
- **Власні повідомлення:** у режимі акаунта можна назвати особисті чати (ім’я, повне ім’я або `@username`), у яких обробляються й файли, надіслані вами. Обране обробляється завжди.
- **Відповідь у чат:** назад ідуть розшифровка, кожен файл AI, MP3, витягнуте з відео, і пізніший відрізок аудіо. MP3, зроблене зі звукового файлу, не надсилається. Чат пам’ятається і після того, як рядок зник із черги.
- **Підказки:** у вікні Telegram короткий текст залежить від режиму, а на кожному полі є пояснення при наведенні.
- **Cursor:** невдалий промпт SDK повторюється до п’яти разів. Відхилений ключ API не повторюється.
- **Два файли поспіль:** якщо Telegram віддає два медіа в одну мить, обидва лишаються в черзі.
- **Ключі на macOS:** API-ключі пишуться в login Keychain; у `settings.json` лишається позначка `keychain:`.

## Що нового в 2.0.7

- **Telegram:** кнопка «Запустити слухача» у вікні Telegram запускає прийом файлів у відкритому FTW. Окремий процес більше не потрібен.
- **Поля вводу:** у порожньому полі видно сірий приклад очікуваного значення (телефон `+380501111111`, ключ, шлях). Приклад не зберігається.

## Що нового в 2.0.6

- **Самооновлення:** ZIP релізу знову розпаковується в каталог `WhisperFastGUI-*`, тож установщики 1.2.17–2.0.5 після перевірки SHA-256 знаходять програму і застосовують оновлення. Новий апдейтер приймає і `FTW-*`, і пише в лог, якщо папки застосунку в архіві немає.
- **Автозапуск:** увімкнення й вимкнення прибирають дублікати з реєстру поточного користувача (`HKCU\...\Run`), якщо це FTW / WhisperFastGUI або команда вказує на цю установку.
- **AI:** якщо файл результату вже існує, запитання «перезаписати» з’являється до виклику моделі, навіть коли відкрите вікно промптів.

## Що нового в 1.2.16

- **Python 3.13 / pydub:** замість неіснуючого пакета `pyaudioop` ставиться `audioop-lts` (модуль `audioop` прибрано зі stdlib).
- **NVIDIA:** якщо в `settings.json` уже є `"gpu_model": "NVIDIA …"` — інсталятор не перевіряє залізо і не питає Y/N; одразу ставить CUDA-torch і `nvidia-cublas-cu12` / `nvidia-cudnn-cu12`.
- **Вибір Python:** якщо з’явився ще один інтерпретатор (наприклад 3.12 після 3.13), діалог вибору показується знову; типово пропонується 3.12.

- **MP3:** чекбокс + кнопка «mp3»; місце збереження — як у «Сохранение», поруч із відео або окремий каталог.
- **Компактний UI:** «Слежение» відкриває список каталогів (без окремої «Каталог»); «В Cursor» відкриває `redactor1.md` (без окремої «Изменить промт»).

## Що нового в 1.1.5

- **Слідкування за кількома каталогами:** прапорець «Слідкування» + кнопка «Каталог»; шляхи зберігаються в `settings.json` через кому.
- **Надійне підхоплення завантажень:** новий файл спочатку в pending (вік ≥ 10 с, розмір стабільний ~15 с, файл відкривається); опитування кожні 10 с; при помилці декодування — до 2 retry.
- **Черга винесена в `queue_manager.py`:** persist `request_queue.json`, додавання/видалення та логіка слідкування в одному модулі.
- **Імена файлів Cursor:** замість `*_edited.md` використовується назва промпта з лапок (`## Промпт №2 "TW_core"` → `*_TW_core.md`).

## Що нового в 1.1.4

- **Вибір Python при першому запуску:** програма знаходить установлені інтерпретатори, пропонує вибір, якщо їх кілька, та зберігає `python_path` і `python_version` у `settings.json`.
- **Єдина версія Python для запуску й залежностей:** `run_whisper.vbs`, `start_delayed.vbs` та `install.bat` використовують збережений інтерпретатор.
- **Cursor SDK на Windows / Python 3.10–3.11:** додано сумісність для запуску локального bridge та послідовної обробки всіх промптів.
- **Компактний UI:** елементи MP3, каталогів і Cursor згруповано в один рядок; поле каталогу збереження скорочено до третини початкової ширини.
- **API-ключ:** кнопка `api_key` відкриває окреме вікно; ключ змінюється лише після натискання «Зберегти», закриття через X скасовує зміни.
- **Залежності:** `cursor-sdk` перевіряється та встановлюється через [Оновлення] / [Залежності].
- **Черга:** у запиті про обробку тільки нових файлів показується їх кількість.
- **Сигнал завершення:** при ввімкненому «У Cursor» звук відтворюється лише після завершення транскрибації та всієї Cursor-постобробки.
