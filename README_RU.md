# Whisper Fast GUI

**Версия 1.1.3** (17.07.2026)

Графический интерфейс для транскрибации аудио и видео на основе Faster-Whisper (OpenAI Whisper).

Репозиторий: https://github.com/magnusua/WhisperFastGUI

---

## Использование на разных ОС

Скрипт поддерживает Windows, Linux и macOS.

### Windows 10/11
- **Запуск:** двойной щелчок по `main.py` или через ярлык (`Whisper Fast GUI.lnk`).
- **Запуск с автоматическим стартом очереди:** в консоли из каталога проекта: `python main.py --transcribe` — программа откроется и через полсекунды автоматически начнёт обработку всей текущей очереди (если очередь не пуста).
- **Без консоли:** `run_whisper.vbs`.
- **Установка зависимостей:** `install.bat` (или кнопка [Зависимости] в программе).
- **Модель:** кнопка с названием текущей модели (например «large-v3-turbo») — слева от переключателя «Трей» — открывает диалог выбора модели Whisper; в диалоге есть кнопки **«Загрузить модель»** и **«Обновить модель»** (проверка новой ревизии на Hugging Face Hub).
- **Панель / Трей / Панель + Трей:** переключатель в нижней панели. В режиме **Трей** закрытие окна (×) не закрывает программу — она скрывается в системный трей и продолжает работать; выход — через меню иконки в трее. Подробнее — раздел «Режимы Панель / Трей / Панель + Трей» ниже.
- **Автозапуск:** кнопка [Автозапуск] в программе (рядом с переключателем «Трей») запускает `autorun_delayed.bat` и добавляет программу в автозагрузку с задержкой 25 с.
- **Щелчок по ссылке в логе:** открытие файла; Shift+щелчок — открыть папку и выделить файл в проводнике.
- **Звук завершения:** при отсутствии файла .mp3 в **каталоге программы** используется системный звук Windows.

### Linux
- **Запуск:** из каталога проекта выполнить: `python3 main.py` (или `python main.py`). Для автоматического старта обработки очереди: `python3 main.py --transcribe`.
- **Drag & Drop и отображение:** нужен рабочий стол с поддержкой X11/Wayland и tkinter.
- **Установка:** установите Python 3, FFmpeg и зависимости (через pip или кнопку [Зависимости]).
- **Открытие файлов и папок из лога:** используется `xdg-open` (пакет `xdg-utils`).
- **Звук завершения:** при отсутствии .mp3 в **каталоге программы** — попытка воспроизвести системный звук (freedesktop); иначе звук не воспроизводится.

### macOS
- **Запуск:** `python3 main.py` из каталога проекта. Для автоматического старта обработки очереди: `python3 main.py --transcribe`.
- **Открытие файлов из лога:** `open` (обычный щелчок) и `open -R` (Shift+щелчок — показать в Finder).
- **Звук завершения:** как на Linux (системные звуки при отсутствии .mp3 в каталоге программы).

На всех ОС нужны: **Python 3.9–3.13** (на практике наиболее стабильно **3.11 или 3.12**), **FFmpeg** в PATH, зависимости (faster-whisper, torch, pydub и т. д.). **Python 3.14+** часто не подходит: для него ещё нет колёс **ctranslate2** / **torch** на PyPI — установка завершается с ошибкой; используйте 3.12. Рекомендуется видеокарта NVIDIA с CUDA для ускорения на Windows и Linux.

## Об оборудовании и скрипте

Скрипт основан на технологии OpenAI Whisper и библиотеке Faster-Whisper. По умолчанию используется модель **large-v3-turbo** (оптимальный баланс качества и скорости). Модель можно изменить: кнопка с названием текущей модели (слева от переключателя «Трей») открывает диалог выбора (tiny, base, small, medium, large-v1/v2/v3, large-v3-turbo, distil-large-v3). В диалоге отображается, какие модели уже загружены и их приблизительный размер; кнопка **«Загрузить модель»** позволяет загрузить выбранную модель в память сразу, без ожидания запуска транскрибации; кнопка **«Обновить модель»** — загрузить новую ревизию весов с Hugging Face Hub. Версия и дата приложения отображаются в верхней части окна (справа от кнопок).

## Автозапуск с задержкой (Windows)

Чтобы программа запускалась при входе в систему с задержкой 20–30 секунд:

**Способ 1 (рекомендуется):** в программе нажмите кнопку **[Автозапуск]** (в нижней панели после переключателя «Трей»). Откроется окно скрипта; после выполнения ярлык появится в каталоге Автозагрузки.

**Способ 2:** запустите **`autorun_delayed.bat`** из папки проекта (двойной щелчок или из CMD). Скрипт создаст ярлык в каталоге Автозагрузки; после следующего входа в Windows программа запустится автоматически через 25 секунд. Скрипт написан одной строкой вызова PowerShell (без продолжения строк), чтобы корректно работать на разных ПК и при разных окончаниях строк в файле.

**Способ 3 (вручную):**
1. Откройте папку **Автозагрузки**: нажмите `Win+R`, введите `shell:startup`, Enter.
2. Создайте **ярлык** на файл `start_delayed.vbs` из папки проекта и переместите его в папку Автозагрузки.
3. По умолчанию задержка — **25 секунд**. Чтобы изменить, отредактируйте `start_delayed.vbs`: измените значение `delaySec = 25` на 20 или 30.

Права администратора не нужны: ярлык создаётся в каталоге автозагрузки текущего пользователя (`%APPDATA%\...\Startup`).

После входа в Windows программа запустится автоматически через указанное количество секунд (без окна CMD).

## Режимы «Панель» / «Трей» / «Панель + Трей» и работа с системным треем

В нижней панели программы есть переключатель режима отображения: **Панель**, **Трей**, **Панель + Трей**. От него зависит, где появляется программа (панель задач, область уведомлений у часов или оба варианта) и **что происходит при нажатии кнопки закрытия окна (×)**.

Нужны библиотеки **pystray** и **Pillow** (кнопки [Зависимости] или [Обновление]). Если они не установлены, режимы «Трей» и «Панель + Трей» недоступны (в логе появится предупреждение).

### Режим «Панель»
- Отображается только на **панели задач**; иконки в системном трее нет.
- **Закрытие окна (×):** появляется диалог «Закрыть программу?» — подтверждение закрывает приложение.

### Режим «Трей»
- Программа показывается только как **иконка в системном трее** (область уведомлений у часов). Окно при запуске скрыто; двойной щелчок по иконке или пункт меню **«Показать окно»** открывают окно.
- **Закрытие окна (×):** окно **не закрывается** — оно скрывается в трей, программа продолжает работать в фоне (в том числе может работать очередь и слежение за каталогом).
- **Полное закрытие программы:** в контекстном меню иконки в трее выберите **«Выход»** — появится обычный диалог подтверждения закрытия.

### Режим «Панель + Трей»
- Программа одновременно на **панели задач** и в **системном трее**.
- **Закрытие окна (×):** как в режиме «Панель» — появляется диалог закрытия; подтверждение закрывает приложение.
- Если нужно оставить программу работать в фоне без закрытия — сверните окно кнопкой «−» (минимизация), а не закрывайте через ×.

### Итог
| Режим           | × закрывает окно? | Где закрыть программу полностью?        |
|-----------------|-------------------|-------------------------------------------|
| Панель          | Да (через диалог) | Кнопка × → «Да» в диалоге                 |
| Трей            | Нет (скрывает в трей) | Меню иконки в трее → «Выход» → «Да»   |
| Панель + Трей   | Да (через диалог) | Кнопка × → «Да» в диалоге                 |

- **Python:** 3.9 или новее (рекомендуется 3.10+). Поддерживается Python 3.13+.
- **ОС:** Windows 10/11, Linux (X11/Wayland), macOS.
- **GPU:** Рекомендуется видеокарта NVIDIA с поддержкой CUDA 12.1. AMD Radeon и другие GPU без CUDA работают только в режиме CPU.

## Очередь (таблица)

Подпись блока — **«Очередь»** (или «Queue» / «Черга» в зависимости от языка). При наведении курсора на эту подпись появляется подсказка с пояснением работы таблицы и отрезков времени.

Очередь отображается как **таблица** с колонками:

| Колонка           | Описание |
|------------------|----------|
| **#**            | Порядковый номер. |
| **Название файла**  | Имя файла (плюс «– обработано», если уже обработан). |
| **Начало**      | Время начала обработки (по умолчанию 00:00:00,000). |
| **Конец отр. 1** | Конец первого отрезка (по умолчанию пусто). |
| **Конец отр. 2** | Конец второго отрезка (по умолчанию пусто). |
| **Конец**       | Время конца обработки (по умолчанию — длительность файла). |

- При добавлении файла **Начало** = 00:00:00,000, **Конец** = длительность файла (из ffprobe/pydub).
- **Двойной щелчок** по строке — диалог редактирования диапазона времени (Начало, Конец отр. 1/2, Конец).
- **Shift + щелчок** по строке — открыть расположение исходного файла в файловом менеджере (на Windows: папка открывается с выделением файла).
- Клавиша **Delete** и ПКМ → **«Удалить»** удаляют выделенный файл(ы); групповое выделение — **Ctrl** и **Shift**.
- Очередь **сохраняется** в `request_queue.json` (добавление, очистка, перетаскивание, редактирование).
- При **запуске** программы очередь подгружается из `request_queue.json` (файлы, которых уже нет на диске, пропускаются).

Обработка выполняется только в диапазоне **[Начало — Конец]** для каждой строки. Так можно обработать один файл по частям (например 0–20 мин на английском, 20–60 мин на русском).

## Функционал

Преобразует речь из аудио и видео в текст. Выходные файлы создаются в каталоге сохранения или рядом с исходным файлом:

1. **.txt** — чистый текст транскрибации (каждый сегмент с новой строки).
2. **.srt** — субтитры: нумерация сегментов, временные метки, текст.

Опционально (при включённой опции «Сохранить извлечённое аудио (MP3)»):
3. **_audio.mp3** — извлечённая аудиодорожка (для полного файла — один файл; для отрезка — отдельный файл с суффиксом времени).

**Обработка по диапазону (отрезками):** если в таблице заданы Начало и/или Конец, отличные от 0 и длительности файла, обрабатывается только этот отрезок. Результаты сохраняются в **отдельные файлы** с суффиксом времени, например:
- `имя_00-00-00_00-20-00.txt` / `.srt` — отрезок 0:00–0:20;
- `имя_00-20-00_01-00-00.txt` / `.srt` — отрезок 0:20–1:00.
При включённом «Сохранить Mp3» для каждого отрезка создаётся отдельный `имя_..._audio.mp3` в том же диапазоне.

## Режимы обработки

- **Один файл в очереди:** выберите файл и нажмите [Старт] — диалог не показывается.
- **Несколько файлов:** при нажатии [Старт] появляется диалог: «Только выбранный файл», «Все файлы в очереди» или «Отмена».
- **Только новые:** обрабатываются только файлы без пометки «– обработано».
- **Вся очередь:** обработка всех файлов по порядку.

## Настройки устройства и модели

- **AUTO** — автоматический выбор (видеокарта NVIDIA при наличии, иначе CPU).
- **GPU** — принудительно видеокарта (если CUDA доступна). Для старых карт — безопасный режим int8.
- **CPU** — принудительно процессор, int8 (подходит также для AMD Radeon и других GPU без CUDA).

**Выбор модели:** кнопка с названием текущей модели (например «large-v3-turbo») открывает диалог, где можно выбрать модель из списка (tiny, base, small, medium, large-v1/v2/v3, large-v3-turbo, distil-large-v3), посмотреть, какие из них уже загружены и их размер, нажать **«Загрузить модель»**, чтобы сразу загрузить выбранную модель в память (без ожидания старта транскрибации), или **«Обновить модель»** — чтобы загрузить новую ревизию весов с Hugging Face Hub (в списке появляется пометка «есть обновление», если на Hub есть более новая версия). Модель загружается один раз и используется для всех файлов (Singleton). Загруженные модели сохраняются в кеше Hugging Face Hub (путь показан в подсказке к кнопке и в диалоге).

**Дополнительные опции:**
- Воспроизвести звук по завершении очереди.
- Сохранить извлечённое аудио (MP3) — для полного файла один `<имя>_audio.mp3`; для отрезка — отдельный файл с суффиксом времени (например `<имя>_00-20-00_01-00-00_audio.mp3`).
- **Отправить TXT в Cursor** — после создания `.txt` (задержка 5 с) обработка промптами из `redactor1.md`.

## Постпроцессинг TXT в Cursor

1. Включите флажок **«Отправить TXT в Cursor»**.
2. При необходимости отредактируйте промпты кнопкой **«Редактировать redactor1.md»** (секции `## Промпт №1`, `## Промпт №2`, …).
3. API-ключ (опционально): поле в GUI → `settings.json` (`cursor_api_key`) или переменная окружения `CURSOR_API_KEY` (имеет приоритет). Файл `settings.json` в git не попадает.

**С ключом (Cursor SDK):** автоматическая цепочка. Пакет `cursor-sdk` ставится через [Зависимости] / [Обновление] (или `pip install cursor-sdk`).
Если пакет отсутствует — появится запрос на установку; без него используется режим Chat.
- Промпт №1 → `<имя>_edited.md`
- Промпт №N → `<имя>_edited_N.md` (вход — предыдущий результат)
В лог пишется каждый созданный файл со ссылкой.

**Без ключа:** открывается **Cursor Chat** с TXT; промпт №1 копируется в буфер — нужно ручное подтверждение. Автоцепочка 2..N в этом режиме не выполняется.

## Языки интерфейса

- **EN** — английский (по умолчанию), **UK** — украинский, **RU** — русский.
- Переключатель (🌐 EN UK RU) в верхней части окна. Язык сохраняется в `settings.json`.
- Кнопка **[Справка]** открывает текст справки на том же языке, что и интерфейс (`README_EN.md` / `README_UK.md` / `README_RU.md`).
- Язык интерфейса не влияет на распознавание речи. Язык распознавания задаёт переключатель «Язык распознавания» (AUTO, RU, UK, EN).

**Флажки:** «Воспроизвести звук по завершении очереди», «Сохранить извлечённое аудио (MP3)», «Отправить TXT в Cursor».

**Слежение за каталогом:** при включённой отметке программа следит за указанным каталогом. Каждый **новый** поддерживаемый файл:
1. **Добавляется в очередь** (таблицу) с диапазоном 00:00:00 — длительность файла.
2. **Автоматически запускается обработка** этого файла. Если в этот момент уже выполняется другая обработка, файл **ставится в очередь** и будет обработан **автоматически после завершения** текущего задания (в лог: «в очереди — обработается после текущего задания»). Одновременно выполняется только **одна** задача транскрибации; звук завершения воспроизводится только когда вся очередь со слежением обработана.

Файлы, которые программа сама создаёт в этом каталоге (`.txt`, `.srt`, экспорт `*_audio.mp3` и т. д.), **не добавляются** в очередь повторно — чтобы избежать цикла, когда сохранение MP3 рядом с исходным файлом снова воспринимается как «новый файл».

## Поведение клавиш

- **Enter** — если очередь пуста: открывается диалог «Добавить файлы»; если есть файлы: запуск транскрибации (как кнопка [Старт]).
- **Пробел (Space)** — переключает отметку «Сохранить Mp3» (в полях ввода работает как обычный пробел).
- **Ctrl+V** — вставка пути из буфера обмена в поле «Слежение за каталогом».
- **Delete** — удалить выделенные файлы из очереди (когда фокус на таблице очереди).

## Полезные возможности

- **Таблица очереди:** подпись «Очередь»; при наведении на неё — подсказка с пояснением колонок и отрезков времени. Шесть колонок (№, название, начало, конец отр. 1/2, конец); двойной щелчок — редактирование времени.
- **Drag & Drop:** перетаскивание файлов в окно; перетаскивание строк в таблице меняет порядок очереди.
- **Сохранение очереди:** `request_queue.json` — очередь сохраняется при изменениях и подгружается при запуске.
- **Умная очередь:** обработанные файлы помечаются «– обработано».
- **Ссылки в логе:** щелчок — открыть файл; Shift+щелчок — открыть папку с файлом в проводнике.
- **Контекстное меню лога:** правый щелчок — копирование текста.
- **Размер лога:** автоматически ограничивается (старые строки удаляются сверху), чтобы избежать чрезмерного потребления памяти при длинных сессиях.
- **Отладка:** если перед запуском установить переменную окружения `DEBUG=1`, в лог выводится полный traceback при ошибках транскрибации.
- **Прогресс-бар** и временные метки сегментов во время обработки.
- **Фильтр VAD:** Voice Activity Detection включён по умолчанию.
- **Иконка:** окно и панель задач используют `favicon.ico` из папки проекта; для иконки в трее при отсутствии файла используется резервная серая иконка.
- **Диалоги:** все всплывающие окна (выбор модели, редактирование времени строки, выбор «только выбранный / все файлы», справка) отображаются по центру главного окна программы (или экрана).
- **Обновление программы:** кнопка [Обновление] сравнивает локальную версию с `config.py` на GitHub (ветка `main`); при наличии git — `git pull`, иначе загрузка ZIP и перезапуск (Windows).
- **Обновление torch на NVIDIA:** если обнаружена видеокарта NVIDIA, для torch используется индекс **CUDA 12.1 (cu121)**, а не обычный PyPI (чтобы не предлагать CPU-сборку).

## Установка и настройка

### Первичная установка

1. **Установите Python 3.9+** (рекомендуется 3.10+). При установке отметьте «Add Python to PATH».  
   https://www.python.org/downloads/

2. **Установите FFmpeg** и добавьте его в PATH.  
   https://ffmpeg.org/download.html

3. **Запустите `install.bat`.** Скрипт:
   - проверяет Python и уже установленные пакеты;
   - обновляет pip, setuptools, wheel;
   - устанавливает PyTorch (CUDA 12.1), faster-whisper, ctranslate2;
   - пропускает nvidia-cublas-cu12 и nvidia-cudnn-cu12 при первой установке (их можно установить из GUI: [Обновление] или [Зависимости]);
   - устанавливает pygame, pydub, tkinterdnd2-universal, pystray, Pillow, cursor-sdk;
   - проверяет пакеты, FFmpeg и CUDA.

4. **Запуск:**
   - `run_whisper.vbs` — двойной щелчок (окно консоли не показывается).
   - Ярлык можно создать вручную: цель — `run_whisper.vbs` или `main.py`.  
   Для отладки из CMD: `py main.py` (из папки проекта).

### Автоматическая установка

При первом запуске скрипт проверяет и устанавливает отсутствующие зависимости (без компонентов NVIDIA). Библиотеки NVIDIA устанавливаются только через [Обновление] или [Зависимости] в GUI.

### Установка вручную

В командной строке в каталоге проекта выполните: `python installer.py`.

## Безопасность и стабильность

- **Безопасное завершение:** при закрытии приложения модель выгружается из памяти, очищается кеш CUDA.
- **Отмена операции:** мгновенная остановка с корректным завершением текущего сегмента.
- **Обработка ошибок:** логирование и корректная реакция на сбои. Если во время обработки возникает ошибка типа «list index out of range», программа показывает подсказку: в файле может **отсутствовать звуковая дорожка** или звука нет — проверьте файл (например, откройте его в медиаплеере).
- **Одна задача одновременно:** в любой момент выполняется только одна транскрибация; повторный [Старт] или новый файл со слежением во время выполнения не запускают вторую задачу параллельно.
