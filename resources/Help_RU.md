# FTW — Справка

FTW преобразует речь из аудио- и видеофайлов в текст и субтитры. В очередь также можно добавлять текстовые и офисные документы (конвертация в Markdown, опционально AI-постпроцессинг и Word).

## Быстрый старт

1. Добавьте медиа или документы кнопками **Добавить файлы**, **Добавить каталог** или перетащите файлы в окно.
2. Для аудио/видео выберите язык распознавания (**AUTO**, **EN**, **UK** или **RU**) и устройство (**AUTO**, **GPU** или **CPU**).
3. При необходимости выберите модель Whisper, нажав иконку микросхемы.
4. Укажите каталог сохранения (пустое поле = рядом с исходным файлом).
5. Выберите элемент очереди и нажмите **Старт**.

Для аудио/видео программа создаёт:
- `.txt` — обычный текст транскрибации;
- `.srt` — субтитры с временными метками;
- `_audio.mp3` — извлечённый звук, если включено **Сохранить MP3**.

Для документов — Markdown (`.md`), опционально результаты AI и Word (`.docx`).

## Добавление файлов и управление очередью

- **Добавить файлы** — выбор одного или нескольких поддерживаемых файлов.
- **Добавить каталог** — добавление поддерживаемых файлов из каталога и его подкаталогов.
- Перетащите файлы в окно, чтобы добавить их.
- Перетаскивайте строки очереди, чтобы изменить порядок обработки.
- Нажмите **Delete** или ПКМ → **Удалить**, чтобы убрать выбранные строки.
- **Очистить очередь** удаляет все строки.
- Очередь сохраняется автоматически и восстанавливается при следующем запуске.

Поддерживаемое аудио: `.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`.

Поддерживаемое видео: `.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.webm`.

Поддерживаемый текст: `.md`, `.markdown`, `.txt`, `.text`, `.rst`, `.csv`, `.html`, `.htm`.

Поддерживаемые документы: `.pdf`, `.doc`, `.docx` (конвертируются в Markdown; Whisper не используется).

## Обработка очереди

- Если в очереди один элемент, кнопка **Старт** сразу запускает его обработку.
- Если элементов несколько, можно обработать выбранный, только новые или всю очередь.
- **Отмена** останавливает текущее задание.
- Обработанные элементы помечаются в очереди.
- Одновременно выполняется только одно задание очереди (транскрибация или документ).

## Документы в очереди

1. PDF/DOC/DOCX конвертируются в `.md` (пакет `markitdown`).
2. Другие текстовые форматы готовятся как Markdown в каталоге сохранения.
3. Если включено **В AI**, открывается окно промптов (Cursor / Gemini / Claude / Copilot); в AI передаётся **Markdown**. В логе указано, что исходный PDF/DOC/DOCX **не** передавался в AI.
4. Если включено **MD → Word**, Pandoc создаёт `.docx` после готовности Markdown (или после каждого результата AI). Если Pandoc нет, программа может установить его через меню **Среда**, либо с https://pandoc.org/installing.html

В логе видны шаги конвертации, пути результатов, ход AI и итог.

## Обработка части файла

Дважды щёлкните строку очереди, чтобы изменить **Начало**, промежуточные границы и **Конец** (аудио/видео). Будет обработан только указанный диапазон. Результаты для диапазонов получают суффикс времени, поэтому части одного файла сохраняются отдельно.

**Shift+щелчок** по строке показывает исходный файл в файловом менеджере.

## Язык, устройство и модель

- **Язык распознавания** — иконка с текущим выбором: **AUTO**, **RU**, **UK** или **EN**. Клик открывает окно выбора. **AUTO** определяет язык речи по записи. **EN**, **UK** и **RU** — если язык известен заранее. Это не меняет язык интерфейса.
- **Устройство: AUTO** использует NVIDIA GPU при наличии, иначе CPU.
- **GPU** использует CUDA. Если видеокарта NVIDIA уснула, FTW сначала будит её; когда карты нет, работа идёт на CPU.
- **CPU** работает без CUDA и подходит для систем с AMD или встроенной графикой.
- Нажмите название модели, чтобы выбрать, скачать, загрузить или обновить модель Whisper. Маленькие модели быстрее, большие обычно точнее.

## Результаты и дополнительные параметры

- **Воспроизвести звук** — уведомление после завершения очереди (в том числе после AI, если включено).
- **Сохранить MP3** — иконка ноты. Клик открывает, куда сохранять файл. Shift+клик или Пробел включает или выключает сохранение. Зелёная иконка — сохранение включено.
- **MD → Word** — иконка документа. Клик показывает справку и состояние Pandoc. Shift+клик включает или выключает экспорт. Зелёная иконка — экспорт включён.
- **Каталог сохранения** — кнопка **Сохранение**: рядом с файлом, выбранный каталог, именная папка рядом с видео или выбранный каталог плюс параметризованное имя подкаталога (`{basename}`).
- Щёлкните ссылку на файл в логе, чтобы открыть его.
- **Shift+щелчок** по ссылке в логе показывает файл в его каталоге.

## Слежение за каталогом

Включайте слежение Shift+щелчком по иконке глаза (открытый — включено, закрытый — выключено). Обычный щелчок открывает список каталогов (сохраняются в `settings.json` через запятую). Если каталогов нет, слежение берёт папку «Загрузки». Новые поддерживаемые файлы сначала попадают в pending: минимальный возраст ≥ 10 с, размер стабилен ~15 с и файл должен открываться. Затем файл добавляется в очередь и обрабатывается. Собственные результаты программы игнорируются. При ошибке декодирования — до 2 повторов из pending.

Если уже выполняется другое задание, новые файлы ожидают в очереди и запускаются после него.

## Постобработка в AI (Cursor / Gemini / Claude / Copilot)

Включите **В AI** (Shift+клик по иконке промтов; зелёная иконка — включено), чтобы обрабатывать созданные `.txt` (после транскрибации) или `.md` (документы) с помощью промптов из каталога `promts/` (отдельный JSON на каждый промт).

- Клик по иконке открывает список промтов. Галочка в строке — выполнять по умолчанию; **Изменить** открывает файл этого промта. Наведите на название, чтобы увидеть краткое описание.
- **API keys** открывается из окна **Промпты**. Это одно окно для ключей Cursor, Gemini, Claude, Azure OpenAI (Copilot), Ollama и OpenAI-compatible URL. **Войти в Gemini** открывает браузер и копирует URL авторизации (как Cursor Chat / Google Календарь). **Проверить соединение** пингует выбранного провайдера. Закрытие через X не сохраняет изменения. На Windows ключи шифруются (DPAPI). На macOS они попадают в login Keychain. Env имеет приоритет: `CURSOR_API_KEY`, `GEMINI_API_KEY` / `GOOGLE_API_KEY`, `ANTHROPIC_API_KEY` / `CLAUDE_API_KEY`, `AZURE_OPENAI_*`, `OLLAMA_HOST`, `OPENAI_BASE_URL` / `OPENAI_API_KEY`.

После Whisper или конвертации документа в логе появляется кликабельное **Передаю в AI** и окно **Промты**:

- выбор интеграции: **Cursor** | **Gemini** | **Claude** | **Copilot**;
- галочки / клик по названию — выбор промптов (предварительно отмечены из обзора **В AI**);
- **Выполнить** (или **Пробел**) — только отмеченные; **Все** — все промпты сразу;
- закрытие окна — без AI; в логе будет ссылка открыть выбор снова.

| Интеграция | С ключом (API) | Без ключа (fallback) |
|------------|----------------|----------------------|
| **Cursor** | Cursor SDK, цепочка промптов | Cursor Chat + промпт в буфере |
| **Gemini** | Google Generative Language API или браузерный OAuth (Desktop + PKCE) | Браузер gemini.google.com + буфер |
| **Claude** | Anthropic Messages API | Браузер claude.ai + буфер |
| **Copilot** | Azure OpenAI (endpoint + key + deployment) | Браузер copilot.microsoft.com + буфер |
| **Ollama** | Локальный демон, без ключа | Нужен запущенный Ollama |
| **OpenAI-compatible** | `/v1/chat/completions` | Браузерный fallback |

## Архив, запись встречи, дополнительный экспорт

- **Архив** показывает обработанные задания (`library.sqlite`). Поиск по тексту расшифровки. Столбец **Кому** перечисляет всех, кому уже ушли результаты. **Отправить в Telegram** отправляет тот же набор файлов, что и очередь; Shift+щелчок всегда спрашивает адресата, даже если чат уже известен. Двойной клик по строке SRT — услышать этот момент (нужен исходник или сохранённый MP3). **Удалить все файлы** убирает исходник и все производные. **Спросить** задаёт вопрос к этой расшифровке через текущего API-провайдера. **Спикеры** переименовывает Вы/Они по первой и самой длинной реплике.
- **Запись** (также трей / **Ctrl+Shift+R**) снимает микрофон + системный звук. PCM пишется на диск по ходу; **Stop** и **Уривок** кодируют в Opus (по умолчанию 24 кбит/с моно), AAC, MP3 или WAV и всегда ставят файл в очередь. **Пауза** / **Ctrl+Shift+P** пропускает звук, пока не продолжите. Шестерёнка открывает **настройки записи**: mix / устройство, кодек, автозапись (Zoom/Teams/Meet/Telegram/Viber/Phone Link/WhatsApp), Google Календарь / Outlook / ICS, токены имени (`%W`, `%C`, …). **Войти в Google Календарь** открывает браузер (как Cursor Chat без API-ключа) и копирует URL авторизации; нужен свой Desktop OAuth client ID (Google не позволяет вшивать чужой). PKCE, secret необязателен. Ручной Start/Stop сильнее автозаписи и календаря. Автостоп по 15 с тишины только для автосессий. В первый раз есть предупреждение сказать комнате. Прерванная запись восстанавливается при следующем запуске.
- В **Сохранении** можно дополнительно писать **JSON**-сегменты, **WebVTT**, таймкоды слов и метки спикеров (Вы/Они). В папке сессии появляются `meta.json`, `speakers.json` и `summary.md`.

Имена выходных файлов — из кавычек в заголовке промпта (напр. `*_TW_core.md` из `## Промпт №2 "TW_core"`). Пустые секции пропускаются.

## Telegram

Иконка Telegram открывает настройки. Shift+клик запускает или останавливает слушателя в этом окне FTW; зелёная иконка означает, что слушатель включён. Если он был включён перед закрытием, слушатель стартует снова вместе с окном. Если аккаунт или бот ещё не заполнены, появляется ошибка: сначала откройте настройки. Пока слушатель работает, FTW должно оставаться открытым. Наведите на поле — подсказка объясняет, откуда взять значение.

Ссылка YouTube, Instagram или Facebook по умолчанию только скачивается и возвращается в чат. Галочка «Ставить видео из соцсетей в очередь Whisper» добавляет ролик в очередь. Режим обучения не обрабатывает новый чат, пока вы не ответите; если закрыть окно вопроса, строка остаётся в логе.

- **Аккаунт** — личные чаты этого Telegram. Нужны `api_id` и `api_hash` с [my.telegram.org](https://my.telegram.org) (API development tools, платформа Desktop) и номер в формате `+380501111111`. **Войти** получает код в Telegram, не по SMS; если есть облачный пароль, программа спросит и его. Слушателя можно запускать только после входа.
- **Бот** — бот от @BotFather: отправьте `/newbot`, username должен заканчиваться на `bot`, токен выглядит как `123456789:AAH…`. Нужны также `api_id`, `api_hash` и локальный `telegram-bot-api.exe` (файлы примерно до 2 ГБ) с [tdlib/telegram-bot-api](https://github.com/tdlib/telegram-bot-api/releases). Адрес по умолчанию — `http://127.0.0.1:8081`. Перед первым локальным запуском вызовите `logOut` облачного Bot API для этого токена.

Аудио и видео попадают в очередь. Как только файл принят, строка появляется в логе FTW, ещё до загрузки. Результаты возвращаются в тот же чат: расшифровка (TXT), каждый файл AI, MP3, извлечённое из видео, и более поздний отрезок аудио (подпись «Отрезок к аудио»). MP3, сделанное из уже звукового файла, обратно не отправляется. Если расшифровку остановили посреди файла, в чат ничего не уходит; уже завершённые файлы и их AI отправляются сами. Тот же файл Telegram (пересылка) не скачивается снова: если он ещё в очереди, результаты уйдут в новое сообщение после обработки; если расшифровка или файлы ИИ уже есть, в чат отправляются готовые файлы. После обработки оригиналы остаются на диске рядом с расшифровкой, в чат уходит копия.

В режиме аккаунта свои сообщения пропускаются, кроме **Избранного** и чатов из поля «Также обрабатывать свои аудио и видео в этих чатах» (имя, полное имя или `@username`, без учёта регистра). Группа с этим названием отдаёт все аудио и видео. При старте слушателя то же сообщение уходит в Избранное. Пустой список chat id означает все личные чаты. В режиме бота, пока список chat id пуст, бот игнорирует медиа и на `/start` отвечает id этого чата.

В очереди столбец с корзиной убирает строку (архив остаётся). Столбец Telegram отправляет результаты тем же набором, что и автоматический ответ. Если файл не привязан к чату, окно спрашивает название группы или контакта и показывает 10 последних адресатов. Shift+щелчок по этому столбцу всегда спрашивает, кому отправить, даже если чат уже известен. Столбец «Статус»: песочные часы — ещё не обработано, галочка — расшифровка готова, `AI` / `TG` / `AI + TG` — следующие шаги, иначе текст ошибки.

## Лог

- Лог сохраняется в `app_log.json` рядом с программой (запись пакетами).
- Записи сгруппированы по дням; прошлые дни подгружаются при разворачивании; **сегодня** всегда развёрнуто.
- Один входной файл — один блок в логе (сегменты, пути TXT/SRT/AI и т.д.).
- **Очистить лог** очищает окно и `app_log.json`. Надпись «Лог» и кнопка стоят слева в одном ряду со стартом.
- Полоса прогресса появляется над логом только во время транскрибации.

## Кнопки

- **Старт** — иконка воспроизведения рядом с иконкой языка распознавания. Начинает обработку очереди.
- **Отмена** — остановить текущее задание.
- **Добавить файлы / Добавить каталог** — добавить медиа или документы.
- **Архив** — поиск прошлых расшифровок; клик по строке чтобы услышать. Столбец **Кому** и кнопка **Отправить в Telegram**.
- **Запись** — микрофон + системный звук в очередь (Ctrl+Shift+R). Пауза — Ctrl+Shift+P. **Уривок** сохраняет последние N секунд; шестерёнка открывает настройки записи.
- **Очистить очередь** — удалить все элементы.
- **Среда** — одна иконка пазла. Меню: **Проверить систему** (Python, FFmpeg, Pandoc, GPU, CUDA), **Проверить обновления** (программа, pip, модели Whisper, FFmpeg/Pandoc; пакет предлагается только если версия новее и подходит к этому Python), **Установить или переустановить** pip-пакеты (в том числе `markitdown`) и системные утилиты.
- **Модель** — иконка микросхемы. Название текущей модели в подсказке. Слева иконка устройства: клик открывает AUTO, GPU или CPU. В режиме GPU видеокарта остаётся в ожидании, пока FTW открыт.
- **Очистить лог** — очистить окно лога и `app_log.json`. Надпись «Лог» и кнопка стоят слева в одном ряду со стартом.
- **Автозапуск** — иконка включает или выключает отложенный запуск в Windows.
- **В AI** — клик открывает окно промтов, Shift+клик включает или выключает AI. Зелёная иконка — AI включён. Ключи API — в окне промтов.
- **Telegram** — клик открывает настройки аккаунта или бота. Shift+клик запускает или останавливает слушателя. Зелёная иконка — слушатель включён.
- **Справка** — открыть этот файл на языке интерфейса. В списке вверху окна можно также читать архитектуру, установку и другие документы из `docs/`.

## Режимы отображения

Иконка панели задач открывает выбор. Текущий режим в меню отмечен.

- **Панель** — программа отображается на панели задач; закрытие окна завершает работу после подтверждения.
- **Трей** — программа работает в системном трее; закрытие окна скрывает его. Для выхода используйте меню значка → **Выход**.
- **Панель + Трей** — программа отображается в обоих местах; закрытие завершает работу после подтверждения.

## Клавиатура и мышь

- **Enter** — добавить файлы при пустой очереди, иначе начать обработку.
- **Пробел** — переключить **Сохранить MP3**, если курсор не в текстовом поле; в окне **Промты** — то же, что **Выполнить**.
- **Delete** — удалить выбранные элементы очереди.
- **Ctrl+V** — вставить путь в поле каталога сохранения (или в строку в окне каталогов слежения).
- **Двойной щелчок по строке** — изменить временной диапазон.
- **Shift+щелчок по строке** — показать исходный файл. Shift+щелчок по столбцу Telegram спрашивает, кому отправить результаты.
- **Клик по ссылке в логе** — открыть файл; **Shift+щелчок** — показать в каталоге.

## Язык интерфейса

Используйте выпадающий список **EN / UK / RU** в верхней части окна. Язык интерфейса не меняет язык распознавания речи.

## Если обработка не запускается

1. Откройте **Среда → Проверить систему** и проверьте Python, FFmpeg, CUDA, Pandoc (для Word) и зависимости.
2. Установите отсутствующие пакеты и утилиты через **Среда → Установить или переустановить**.
3. Если не работает GPU, выберите **AUTO** или **CPU**.
