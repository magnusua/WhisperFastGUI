# FTW — Довідка

FTW перетворює мовлення з аудіо та відео на текст і субтитри. У чергу також можна додавати текстові й офісні документи (конвертація в Markdown, опційно AI-постпроцесинг і Word).

## Швидкий старт

1. Додайте медіа або документи кнопками **Додати файли**, **Додати каталог** або перетягніть файли у вікно.
2. Для аудіо/відео виберіть мову розпізнавання (**AUTO**, **EN**, **UK** або **RU**) і пристрій (**AUTO**, **GPU** або **CPU**).
3. За потреби виберіть модель Whisper, натиснувши іконку мікросхеми.
4. Укажіть каталог збереження (порожнє поле = поруч із вихідним файлом).
5. Виберіть елемент черги й натисніть **Старт**.

Для аудіо/відео програма створює:
- `.txt` — звичайний текст транскрибації;
- `.srt` — субтитри з часовими мітками;
- `_audio.mp3` — витягнутий звук, якщо увімкнено **Зберегти MP3**.

Для документів — Markdown (`.md`), опційно результати AI і Word (`.docx`).

## Додавання файлів і керування чергою

- **Додати файли** — вибір одного або кількох підтримуваних файлів.
- **Додати каталог** — додавання підтримуваних файлів із каталогу та підкаталогів.
- Перетягніть файли у вікно, щоб додати їх.
- Перетягуйте рядки черги, щоб змінити порядок обробки.
- Натисніть **Delete** або ПКМ → **Видалити**, щоб прибрати вибрані рядки.
- **Очистити чергу** видаляє всі рядки.
- Черга зберігається автоматично і відновлюється при наступному запуску.

Підтримуване аудіо: `.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`.

Підтримуване відео: `.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.webm`.

Підтримуваний текст: `.md`, `.markdown`, `.txt`, `.text`, `.rst`, `.csv`, `.html`, `.htm`.

Підтримувані документи: `.pdf`, `.doc`, `.docx` (конвертуються в Markdown; Whisper не використовується).

## Обробка черги

- Якщо в черзі один елемент, **Старт** одразу запускає його обробку.
- Якщо елементів кілька, можна обробити вибраний, лише нові або всю чергу.
- **Скасувати** зупиняє поточне завдання.
- Обробленим елементам ставиться позначка в черзі.
- Одночасно виконується лише одне завдання черги (транскрибація або документ).

## Документи в черзі

1. PDF/DOC/DOCX конвертуються в `.md` (пакет `markitdown`).
2. Інші текстові формати готуються як Markdown у каталозі збереження.
3. Якщо увімкнено **В AI**, відкривається вікно промптів (Cursor / Gemini / Claude / Copilot); у AI передається **Markdown**. У логу зазначено, що вихідний PDF/DOC/DOCX **не** передавався в AI.
4. Якщо увімкнено **MD → Word**, Pandoc створює `.docx` після готовності Markdown (або після кожного результату AI). Якщо Pandoc немає, програма може встановити його через меню **Середовище**, або з https://pandoc.org/installing.html

У логу видно кроки конвертації, шляхи результатів, хід AI і підсумок.

## Обробка частини файлу

Двічі клацніть рядок черги, щоб змінити **Початок**, проміжні межі та **Кінець** (аудіо/відео). Буде оброблено лише вказаний діапазон. Результати для діапазонів отримують суфікс часу, тому частини одного файлу зберігаються окремо.

**Shift+клік** по рядку показує вихідний файл у файловому менеджері.

## Мова, пристрій і модель

- **Мова розпізнавання** — іконка з поточним вибором: **AUTO**, **RU**, **UK** або **EN**. Клік відкриває вікно вибору. **AUTO** визначає мову мовлення з запису. **EN**, **UK** і **RU** — якщо мова відома заздалегідь. Це не змінює мову інтерфейсу.
- **Пристрій: AUTO** використовує NVIDIA GPU за наявності, інакше CPU.
- **GPU** використовує CUDA. Якщо відеокарта NVIDIA заснула, FTW спочатку будить її; коли картки немає, робота йде на CPU.
- **CPU** працює без CUDA і підходить для систем з AMD або вбудованою графікою.
- Натисніть назву моделі, щоб вибрати, завантажити або оновити модель Whisper. Менші моделі швидші, більші зазвичай точніші.

## Результати та додаткові параметри

- **Відтворити звук** — сповіщення після завершення черги (зокрема після AI, якщо увімкнено).
- **Зберегти MP3** — іконка ноти. Клік відкриває, куди зберігати файл. Shift+клік або Пробіл вмикає або вимикає збереження. Зелена іконка — збереження увімкнено.
- **MD → Word** — іконка документа. Клік показує довідку і стан Pandoc. Shift+клік вмикає або вимикає експорт. Зелена іконка — експорт увімкнено.
- **Каталог збереження** — кнопка **Збереження**: поруч із файлом, вибраний каталог, іменована папка поруч із відео або вибраний каталог плюс параметризована назва підкаталогу (`{basename}`).
- Клацніть посилання на файл у логу, щоб відкрити його.
- **Shift+клік** по посиланню в логу показує файл у його каталозі.

## Слідкування за каталогом

Увімкніть слідкування Shift+кліком по іконці ока (відкрите — увімкнено, закрите — вимкнено). Звичайний клік відкриває список каталогів (зберігаються в `settings.json` через кому). Якщо каталогів немає, стеження бере папку «Завантаження». Нові підтримувані файли спочатку потрапляють у pending: мінімальний вік ≥ 10 с, розмір стабільний ~15 с і файл має відкриватися. Потім файл додається в чергу й обробляється. Власні результати програми ігноруються. При помилці декодування — до 2 повторів із pending.

Якщо вже виконується інше завдання, нові файли очікують у черзі й запускаються після нього.

## Постобробка в AI (Cursor / Gemini / Claude / Copilot)

Увімкніть **В AI** (Shift+клік по іконці промптів; зелена іконка — увімкнено), щоб обробляти створені `.txt` (після транскрибації) або `.md` (документи) за допомогою промптів із каталогу `promts/` (окремий JSON на кожен промпт).

- Клік по іконці відкриває список промптів. Галочка в рядку — виконувати за замовчуванням; **Змінити** відкриває файл цього промпту. Наведіть на назву, щоб побачити короткий опис.
- **API keys** відкривається з вікна **Промпти**. Це одне вікно для ключів Cursor, Gemini, Claude, Azure OpenAI (Copilot), Ollama та OpenAI-compatible URL. **Увійти в Gemini** відкриває браузер і копіює URL авторизації (як Cursor Chat / Google Календар). **Перевірити з'єднання** пінгує обраного провайдера. Закриття через X не зберігає зміни. На Windows ключі шифруються (DPAPI). На macOS вони потрапляють у login Keychain. Env має пріоритет: `CURSOR_API_KEY`, `GEMINI_API_KEY` / `GOOGLE_API_KEY`, `ANTHROPIC_API_KEY` / `CLAUDE_API_KEY`, `AZURE_OPENAI_*`, `OLLAMA_HOST`, `OPENAI_BASE_URL` / `OPENAI_API_KEY`.

Після Whisper або конвертації документа в логу з’являється клікабельне **Передаю в AI** і вікно **Промти**:

- вибір інтеграції: **Cursor** | **Gemini** | **Claude** | **Copilot**;
- галочки / клік по назві — вибір промптів (попередньо позначені з огляду **В AI**);
- **Виконати** (або **Пробіл**) — лише відмічені; **Всі** — усі промпти одразу;
- закриття вікна — без AI; у логу буде посилання відкрити вибір знову.

| Інтеграція | З ключем (API) | Без ключа (fallback) |
|------------|----------------|----------------------|
| **Cursor** | Cursor SDK, ланцюжок промптів | Cursor Chat + промпт у буфері |
| **Gemini** | Google Generative Language API або браузерний OAuth (Desktop + PKCE) | Браузер gemini.google.com + буфер |
| **Claude** | Anthropic Messages API | Браузер claude.ai + буфер |
| **Copilot** | Azure OpenAI (endpoint + key + deployment) | Браузер copilot.microsoft.com + буфер |
| **Ollama** | Локальний демон, без ключа | Потрібен запущений Ollama |
| **OpenAI-compatible** | `/v1/chat/completions` | Браузерний fallback |

## Архів, запис зустрічі, додатковий експорт

- **Архів** показує оброблені завдання (`library.sqlite`). Пошук по тексту розшифровки. Стовпець **Кому** перелічує всіх, кому вже пішли результати. **Надіслати в Telegram** відправляє той самий набір файлів, що й черга; Shift+клік завжди питає адресата, навіть якщо чат уже відомий. Подвійний клік по рядку SRT — почути цей момент (потрібне джерело або збережений MP3). **Видалити всі файли** прибирає джерело і всі похідні. **Запитати** ставить питання до цієї розшифровки через поточний API-провайдер. **Спікери** перейменовує Ви/Вони за першою та найдовшою реплікою.
- **Запис** (також трей / **Ctrl+Shift+R**) знімає мікрофон + системний звук. PCM пишеться на диск під час запису; **Stop** і **Уривок** кодують у Opus (типово 24 кбіт/с моно), AAC, MP3 або WAV і завжди ставлять файл у чергу. **Пауза** / **Ctrl+Shift+P** пропускає звук, доки не продовжите. Шестерня відкриває **налаштування запису**: mix / пристрій, кодек, автозапис (Zoom/Teams/Meet/Telegram/Viber/Phone Link/WhatsApp), Google Календар / Outlook / ICS, токени імені (`%W`, `%C`, …). **Увійти в Google Календар** відкриває браузер (як Cursor Chat без API-ключа) і копіює URL авторизації; потрібен власний Desktop OAuth client ID (Google не дозволяє вшивати чужий). PKCE, secret необов’язковий. Ручний Start/Stop сильніший за автозапис і календар. Автостоп за 15 с тиші лише для автосесій. Першого разу є попередження сказати кімнаті. Перерваний запис відновлюється при наступному запуску.
- У **Збереженні** можна додатково писати **JSON**-сегменти, **WebVTT**, таймкоди слів і мітки спікерів (Ви/Вони). У папці сесії з’являються `meta.json`, `speakers.json` і `summary.md`.

Імена вихідних файлів — з лапок у заголовку промпта (напр. `*_TW_core.md` з `## Промпт №2 "TW_core"`). Порожні секції пропускаються.

## Telegram

Іконка Telegram відкриває налаштування. Shift+клік запускає або зупиняє слухача в цьому вікні FTW; зелена іконка означає, що слухач увімкнено. Якщо він був увімкнений перед закриттям, слухач стартує знову разом із вікном. Якщо акаунт або бот ще не заповнені, з’являється помилка: спочатку відкрийте налаштування. Поки слухач працює, FTW має лишатися відкритим. Наведіть на поле — підказка пояснює, звідки взяти значення.

Посилання YouTube, Instagram і Facebook за замовчуванням лише скачуються і повертаються в чат. Галочка «Ставити відео з соцмереж у чергу Whisper» додає ролик у чергу. У налаштуваннях Telegram можна брати голос, відео і посилання, лише голос і відео, або лише посилання. Режим навчання не обробляє новий чат, доки ви не відповісте. Питання лише вирішує, брати файл чи ні. Кілька файлів з одного чату за кілька секунд питаються разом. «Ні» більше не обробляє цей чат. Закриття вікна або 10 секунд без відповіді пропускає лише цей файл. Рядок «Обробити?» у логу відкриває питання знову.

- **Акаунт** — особисті чати цього Telegram. Потрібні `api_id` і `api_hash` з [my.telegram.org](https://my.telegram.org) (API development tools, платформа Desktop) і номер у форматі `+380501111111`. **Увійти** отримує код у Telegram, не SMS; якщо є хмарний пароль, програма запитає і його. Слухач стартує лише після входу.
- **Бот** — бот від @BotFather: надішліть `/newbot`, username має закінчуватися на `bot`, токен виглядає як `123456789:AAH…`. Потрібні також `api_id`, `api_hash` і локальний `telegram-bot-api.exe` (файли приблизно до 2 ГБ) з [tdlib/telegram-bot-api](https://github.com/tdlib/telegram-bot-api/releases). Адреса за замовчуванням — `http://127.0.0.1:8081`. Перед першим локальним запуском викличте `logOut` хмарного Bot API для цього токена.

Аудіо та відео потрапляють у чергу. Щойно файл прийнято, рядок з’являється в лозі FTW, ще до завантаження. Результати повертаються в той самий чат: розшифровка (TXT), кожен файл AI, MP3, витягнуте з відео, і пізніший відрізок аудіо (підпис «Відрізок до аудіо»). MP3, зроблене з уже звукового файлу, назад не надсилається. Якщо розшифровку зупинили посеред файлу, у чат нічого не йде; уже завершені файли і їхній AI відправляються самі. Той самий файл Telegram (пересилання) не качається знову: якщо він ще в черзі, результати підуть у нове повідомлення після обробки; якщо розшифровка або ШІ вже є, у чат надсилаються готові файли. Після обробки оригінали лишаються на диску поруч із розшифровкою, у чат іде копія.

У режимі акаунта власні повідомлення пропускаються, крім **Обраного** і чатів із поля «Також обробляти свої аудіо та відео в цих чатах» (ім’я, повне ім’я або `@username`, без урахування регістру). Група з тією назвою віддає всі аудіо та відео. Під час старту слухача те саме повідомлення йде в Обране. Порожній список chat id означає всі особисті чати. У режимі бота, поки список chat id порожній, бот ігнорує медіа і на `/start` відповідає id цього чату.

У черзі стовпець із кошиком прибирає рядок (архів лишається). Стовпець Telegram надсилає результати тим самим набором, що й автоматична відповідь. Якщо файл не прив’язаний до чату, вікно питає назву групи або контакту і показує 10 останніх адресатів. Shift+клік по цьому стовпцю завжди питає, кому відправити, навіть якщо чат уже відомий. Стовпець «Статус»: пісковий годинник — ще не оброблено, галочка — розшифровка готова, `AI` / `TG` / `AI + TG` — подальші кроки, інакше текст помилки.

## Лог

- Лог зберігається в `app_log.json` поруч із програмою (запис пакетами).
- Записи згруповані по днях; минулі дні підвантажуються при розгортанні; **сьогодні** завжди розгорнуте.
- Один вхідний файл — один блок у логу (сегменти, шляхи TXT/SRT/AI тощо).
- **Очистити лог** очищає вікно і `app_log.json`. Напис «Лог» і кнопка стоять зліва в одному ряду зі стартом.
- Смуга прогресу з’являється над логом лише під час транскрибації.

## Кнопки

- **Старт** — іконка відтворення поруч з іконкою мови розпізнавання. Починає обробку черги.
- **Скасувати** — зупинити поточне завдання.
- **Додати файли / Додати каталог** — додати медіа або документи.
- **Архів** — пошук минулих розшифровок; клік по рядку щоб почути. Стовпець **Кому** і кнопка **Надіслати в Telegram**.
- **Запис** — мікрофон + системний звук у чергу (Ctrl+Shift+R). Пауза — Ctrl+Shift+P. **Уривок** зберігає останні N секунд; шестерня відкриває налаштування запису.
- **Очистити чергу** — видалити всі елементи.
- **Середовище** — одна іконка пазла. Меню: **Перевірити систему** (Python, FFmpeg, Pandoc, GPU, CUDA), **Перевірити оновлення** (програма, pip, моделі Whisper, FFmpeg/Pandoc; пакет пропонується лише якщо версія новіша і підходить до цього Python), **Встановити або перевстановити** pip-пакети (зокрема `markitdown`) і системні утиліти.
- **Модель** — іконка мікросхеми. Назва поточної моделі в підказці. Ліворуч іконка пристрою: клік відкриває AUTO, GPU або CPU. У режимі GPU відеокарта лишається в очікуванні, поки FTW відкрито.
- **Очистити лог** — очистити вікно логу та `app_log.json`.
- **Автозапуск** — іконка вмикає або вимикає відкладений запуск у Windows.
- **В AI** — клік відкриває вікно промптів, Shift+клік вмикає або вимикає AI. Зелена іконка — AI увімкнено. Ключі API — у вікні промптів.
- **Telegram** — клік відкриває налаштування акаунта або бота. Shift+клік запускає або зупиняє слухача. Зелена іконка — слухач увімкнено.
- **Довідка** — відкрити цей файл мовою інтерфейсу. У списку вгорі вікна можна також читати архітектуру, встановлення та інші документи з `docs/`.

## Режими відображення

Іконка панелі задач відкриває вибір. Поточний режим у меню позначений.

- **Панель** — програма відображається на панелі завдань; закриття вікна завершує роботу після підтвердження.
- **Трей** — програма працює в системному треї; закриття вікна приховує його. Для виходу використовуйте меню значка → **Вихід**.
- **Панель + Трей** — програма відображається в обох місцях; закриття завершує роботу після підтвердження.

## Клавіатура й миша

- **Enter** — додати файли за порожньої черги, інакше почати обробку.
- **Пробіл** — перемкнути **Зберегти MP3**, якщо курсор не в текстовому полі; у вікні **Промти** — те саме, що **Виконати**.
- **Delete** — видалити вибрані елементи черги.
- **Ctrl+V** — вставити шлях у поле каталогу збереження (або в рядок у вікні каталогів слідкування).
- **Подвійний клік по рядку** — змінити часовий діапазон.
- **Shift+клік по рядку** — показати вихідний файл. Shift+клік по стовпцю Telegram питає, кому надіслати результати.
- **Клік по посиланню в логу** — відкрити файл; **Shift+клік** — показати в каталозі.

## Мова інтерфейсу

Використовуйте випадаючий список **EN / UK / RU** у верхній частині вікна. Мова інтерфейсу не змінює мову розпізнавання мовлення.

## Якщо обробка не запускається

1. Відкрийте **Середовище → Перевірити систему** й перевірте Python, FFmpeg, CUDA, Pandoc (для Word) та залежності.
2. Установіть відсутні пакети й утиліти через **Середовище → Встановити або перевстановити**.
3. Якщо не працює GPU, виберіть **AUTO** або **CPU**.
4. Переконайтеся, що медіафайл містить звукову доріжку.
5. Перегляньте точне повідомлення про помилку в лозі.
