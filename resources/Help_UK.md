# Whisper Fast GUI — Довідка

Whisper Fast GUI перетворює мовлення з аудіо- та відеофайлів на текст і субтитри.

## Швидкий старт

1. Додайте медіа кнопками **Додати файли**, **Додати каталог** або перетягніть файли у вікно.
2. Виберіть мову розпізнавання: **AUTO**, **EN**, **UK** або **RU**.
3. Виберіть пристрій: **AUTO**, **GPU** або **CPU**.
4. За потреби виберіть модель Whisper, натиснувши кнопку з її назвою.
5. Укажіть каталог збереження. Залиште поле порожнім, щоб зберігати поруч із вихідним файлом.
6. Виберіть елемент черги й натисніть **Старт**.

Програма створює:
- `.txt` — звичайний текст транскрибації;
- `.srt` — субтитри з часовими мітками;
- `_audio.mp3` — витягнутий звук, якщо ввімкнено **Зберегти MP3**.

## Додавання файлів і керування чергою

- **Додати файли** — вибір одного або кількох підтримуваних файлів.
- **Додати каталог** — додавання підтримуваних файлів із каталогу та його підкаталогів.
- Перетягніть файли у вікно, щоб додати їх.
- Перетягуйте рядки черги, щоб змінити порядок обробки.
- Натисніть **Delete** або ПКМ → **Видалити**, щоб прибрати вибрані рядки.
- **Очистити чергу** видаляє всі рядки.
- Черга зберігається автоматично й відновлюється під час наступного запуску.

Підтримуване аудіо: `.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`.

Підтримуване відео: `.mp4`, `.mkv`, `.avi`, `.mov`.

## Обробка черги

- Якщо в черзі один елемент, кнопка **Старт** одразу запускає його обробку.
- Якщо елементів кілька, можна обробити вибраний, лише нові або всю чергу.
- **Скасувати** зупиняє поточне завдання.
- Оброблені елементи позначаються в черзі.
- Одночасно виконується лише одна транскрибація.

## Обробка частини файла

Двічі клацніть рядок черги, щоб змінити **Початок**, проміжні межі та **Кінець**. Буде оброблено лише вказаний діапазон. Результати для діапазонів отримують часовий суфікс, тому частини одного файла зберігаються окремо.

**Shift+клік** по рядку показує вихідний файл у файловому менеджері.

## Мова, пристрій і модель

- **Мова розпізнавання: AUTO** визначає мову мовлення автоматично.
- Виберіть **EN**, **UK** або **RU**, якщо мова відома заздалегідь.
- **Пристрій: AUTO** використовує NVIDIA GPU за наявності, інакше CPU.
- **GPU** примусово використовує CUDA.
- **CPU** працює без CUDA й підходить для систем з AMD або вбудованою графікою.
- Натисніть назву моделі, щоб вибрати, завантажити або оновити модель Whisper. Менші моделі швидші, більші зазвичай точніші.

## Результати й додаткові параметри

- **Відтворити звук** — сповіщення після завершення черги.
- **Зберегти MP3** — витягування оброблюваного звуку в окремий файл.
- **Каталог збереження** — місце для результатів. Порожнє поле означає збереження поруч із вихідним файлом.
- Клацніть посилання на файл у лозі, щоб відкрити його.
- **Shift+клік** по посиланню в лозі показує файл у його каталозі.

## Слідкування за каталогом

Увімкніть **Слідкування** і кнопкою **Каталог** задайте один або кілька каталогів (зберігаються в `settings.json` через кому). Нові підтримувані файли спочатку потрапляють у pending: мінімальний вік ≥ 10 с, розмір має бути стабільним ~15 с і файл має відкриватися. Потім файл додається в чергу й обробляється. Власні результати програми ігноруються. При помилці декодування — до 2 повторів із pending.

Якщо вже виконується інше завдання, нові файли очікують у черзі й запускаються після нього.

## Постобробка в Cursor

Увімкніть **У Cursor**, щоб обробляти створені `.txt` за допомогою промптів із `redactor1.md`.

- **Змінити промпт** відкриває файл промптів.
- **api_key** зберігає ключ Cursor для автоматичної обробки.
- За наявності робочого ключа й Cursor SDK промпти виконуються послідовно та створюють файли з назвою промпта (напр. `*_TW_core.md` з `## Промпт №2 "TW_core"`).
- Без ключа відкривається Cursor Chat, а перший промпт копіюється для ручного підтвердження.

## Кнопки

- **Старт** — почати транскрибацію.
- **Скасувати** — зупинити поточне завдання.
- **Додати файли / Додати каталог** — додати медіа.
- **Очистити чергу** — видалити всі елементи.
- **Система** — перевірити Python, FFmpeg, GPU, CUDA та компоненти.
- **Залежності** — установити або перевстановити потрібні пакети.
- **Оновлення** — перевірити оновлення програми, пакетів і моделей.
- **Назва моделі** — вибір і керування моделлю Whisper.
- **Очистити лог** — видалити повідомлення з логу.
- **Автозапуск** — додати відкладений запуск у Windows.
- **Довідка** — відкрити цей файл мовою інтерфейсу.

## Режими відображення

- **Панель** — програма відображається на панелі завдань; закриття вікна завершує роботу після підтвердження.
- **Трей** — програма працює в системному треї; закриття вікна приховує його. Для виходу використовуйте меню значка → **Вихід**.
- **Панель + Трей** — програма відображається в обох місцях; закриття завершує роботу після підтвердження.

## Клавіатура й миша

- **Enter** — додати файли за порожньої черги, інакше почати обробку.
- **Пробіл** — перемкнути **Зберегти MP3**, якщо курсор не перебуває в текстовому полі.
- **Delete** — видалити вибрані елементи черги.
- **Ctrl+V** — вставити шлях у поле каталогу збереження (або в рядок у вікні каталогів слідкування).
- **Подвійний клік по рядку** — змінити часовий діапазон.
- **Shift+клік по рядку** — показати вихідний файл.

## Мова інтерфейсу

Використовуйте перемикач **EN / UK / RU** у верхній частині вікна. Мова інтерфейсу не змінює мову розпізнавання мовлення.

## Якщо обробка не запускається

1. Відкрийте **Система** й перевірте Python, FFmpeg, CUDA та залежності.
2. Установіть відсутні пакети через **Залежності**.
3. Якщо не працює GPU, виберіть **AUTO** або **CPU**.
4. Переконайтеся, що вихідний файл містить звукову доріжку.
5. Перегляньте точне повідомлення про помилку в лозі.
