# Whisper Fast GUI — Справка

Whisper Fast GUI преобразует речь из аудио- и видеофайлов в текст и субтитры.

## Быстрый старт

1. Добавьте медиа кнопками **Добавить файлы**, **Добавить каталог** или перетащите файлы в окно.
2. Выберите язык распознавания: **AUTO**, **EN**, **UK** или **RU**.
3. Выберите устройство: **AUTO**, **GPU** или **CPU**.
4. При необходимости выберите модель Whisper, нажав кнопку с её названием.
5. Укажите каталог сохранения. Оставьте поле пустым, чтобы сохранять рядом с исходным файлом.
6. Выберите элемент очереди и нажмите **Старт**.

Программа создаёт:
- `.txt` — обычный текст транскрибации;
- `.srt` — субтитры с временными метками;
- `_audio.mp3` — извлечённый звук, если включено **Сохранить MP3**.

## Добавление файлов и управление очередью

- **Добавить файлы** — выбор одного или нескольких поддерживаемых файлов.
- **Добавить каталог** — добавление поддерживаемых файлов из каталога и его подкаталогов.
- Перетащите файлы в окно, чтобы добавить их.
- Перетаскивайте строки очереди, чтобы изменить порядок обработки.
- Нажмите **Delete** или ПКМ → **Удалить**, чтобы убрать выбранные строки.
- **Очистить очередь** удаляет все строки.
- Очередь сохраняется автоматически и восстанавливается при следующем запуске.

Поддерживаемое аудио: `.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`.

Поддерживаемое видео: `.mp4`, `.mkv`, `.avi`, `.mov`.

## Обработка очереди

- Если в очереди один элемент, кнопка **Старт** сразу запускает его обработку.
- Если элементов несколько, можно обработать выбранный, только новые или всю очередь.
- **Отмена** останавливает текущее задание.
- Обработанные элементы помечаются в очереди.
- Одновременно выполняется только одна транскрибация.

## Обработка части файла

Дважды щёлкните строку очереди, чтобы изменить **Начало**, промежуточные границы и **Конец**. Будет обработан только указанный диапазон. Результаты для диапазонов получают суффикс времени, поэтому части одного файла сохраняются отдельно.

**Shift+щелчок** по строке показывает исходный файл в файловом менеджере.

## Язык, устройство и модель

- **Язык распознавания: AUTO** определяет язык речи автоматически.
- Выберите **EN**, **UK** или **RU**, если язык заранее известен.
- **Устройство: AUTO** использует NVIDIA GPU при наличии, иначе CPU.
- **GPU** принудительно использует CUDA.
- **CPU** работает без CUDA и подходит для систем с AMD или встроенной графикой.
- Нажмите название модели, чтобы выбрать, скачать, загрузить или обновить модель Whisper. Маленькие модели быстрее, большие обычно точнее.

## Результаты и дополнительные параметры

- **Воспроизвести звук** — уведомление после завершения очереди.
- **Сохранить MP3** — извлечение обрабатываемого звука в отдельный файл.
- **Каталог сохранения** — место для результатов. Пустое поле означает сохранение рядом с исходным файлом.
- Щёлкните ссылку на файл в логе, чтобы открыть его.
- **Shift+щелчок** по ссылке в логе показывает файл в его каталоге.

## Слежение за каталогом

Включите слежение и выберите каталог. Новые поддерживаемые файлы будут автоматически добавляться и обрабатываться. Файлы, созданные Whisper Fast GUI, игнорируются, чтобы не возникал цикл повторной обработки.

Если уже выполняется другое задание, новые файлы ожидают в очереди и запускаются после него.

## Постобработка в Cursor

Включите **В Cursor**, чтобы обрабатывать созданные `.txt` с помощью промптов из `redactor1.md`.

- **Изменить промпт** открывает файл промптов.
- **api_key** сохраняет ключ Cursor для автоматической обработки.
- При наличии рабочего ключа и Cursor SDK промпты выполняются последовательно и создают файлы `_edited.md`.
- Без ключа открывается Cursor Chat, а первый промпт копируется для ручного подтверждения.

## Кнопки

- **Старт** — начать транскрибацию.
- **Отмена** — остановить текущее задание.
- **Добавить файлы / Добавить каталог** — добавить медиа.
- **Очистить очередь** — удалить все элементы.
- **Система** — проверить Python, FFmpeg, GPU, CUDA и компоненты.
- **Зависимости** — установить или переустановить нужные пакеты.
- **Обновление** — проверить обновления программы, пакетов и моделей.
- **Название модели** — выбор и управление моделью Whisper.
- **Очистить лог** — удалить сообщения из лога.
- **Автозапуск** — добавить отложенный запуск в Windows.
- **Справка** — открыть этот файл на языке интерфейса.

## Режимы отображения

- **Панель** — программа видна на панели задач; закрытие окна завершает работу после подтверждения.
- **Трей** — программа работает в системном трее; закрытие окна скрывает его. Для выхода используйте меню значка → **Выход**.
- **Панель + Трей** — программа видна в обоих местах; закрытие завершает работу после подтверждения.

## Клавиатура и мышь

- **Enter** — добавить файлы при пустой очереди, иначе начать обработку.
- **Пробел** — переключить **Сохранить MP3**, если курсор не находится в текстовом поле.
- **Delete** — удалить выбранные элементы очереди.
- **Ctrl+V** — вставить путь в поле слежения за каталогом.
- **Двойной щелчок по строке** — изменить временной диапазон.
- **Shift+щелчок по строке** — показать исходный файл.

## Язык интерфейса

Используйте переключатель **EN / UK / RU** в верхней части окна. Язык интерфейса не изменяет язык распознавания речи.

## Если обработка не запускается

1. Откройте **Система** и проверьте Python, FFmpeg, CUDA и зависимости.
2. Установите отсутствующие пакеты через **Зависимости**.
3. Если не работает GPU, выберите **AUTO** или **CPU**.
4. Убедитесь, что исходный файл содержит звуковую дорожку.
5. Посмотрите точное сообщение об ошибке в логе.
